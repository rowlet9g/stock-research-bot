# 포트폴리오 시나리오 계약

`portfolio-scenarios`는 현재 포트폴리오 평가 결과에 동일한 가격 수익률 충격을
적용하는 결정론적 스트레스 테스트입니다. 미래 가격 예측이나 매수·매도 신호가
아닙니다.

## 실행

```powershell
go run ./cmd/forgetmenot portfolio-scenarios -output text
go run ./cmd/forgetmenot portfolio-scenarios -downside-bps -1500 -upside-bps 2500 -output json
```

기본 시나리오는 다음과 같습니다.

| 시나리오 | 가격 충격 | 확률 |
| --- | ---: | --- |
| 하락 | -2,000bp (-20%) | 추정하지 않음 |
| 중립 | 0bp (0%) | 추정하지 않음 |
| 상승 | 2,000bp (+20%) | 추정하지 않음 |

확률 필드는 항상 `not_estimated`입니다. 근거 데이터 없이 25%, 50% 같은 숫자를
배정하지 않습니다.

## 계산

- 시나리오 변화액 = 현재 평가금액 x 시나리오 수익률
- 시나리오 평가금액 = 현재 평가금액 + 시나리오 변화액
- 시나리오 총 노출액 = 각 시나리오 평가금액 절댓값의 합

숏 포지션은 현재 평가금액이 음수이므로 가격 하락 시 변화액이 양수가 되고 가격
상승 시 변화액이 음수가 됩니다. 계산 중 롱·숏 방향을 제거하지 않습니다.

## 입력 연결

결과에는 입력 포트폴리오 평가의 버전, 상태, 생성시각과 전체 JSON의 SHA-256이
포함됩니다. 같은 평가 입력과 같은 설정은 같은 계산 결과를 만듭니다. 결과
생성시각은 해시 대상인 입력 평가와 별도로 기록됩니다.

## 한계

- 모든 평가 가능 종목에 같은 가격 충격을 적용합니다.
- 종목, 섹터, 국가별 상관관계나 서로 다른 민감도를 추정하지 않습니다.
- 환율을 적용하지 않으며 KRW와 USD 결과를 합산하지 않습니다.
- 가격이 없는 포지션은 제외하고 전체 상태를 `partial`로 유지합니다.
- 투자 가설의 무효화 조건을 자동 판정하지 않습니다.

따라서 결과는 포트폴리오가 균일 충격에 얼마나 민감한지 확인하는 기준선입니다.
실제 투자 판단 전에는 종목별 민감도, 가설 무효화 조건과 거시환경을 별도로
검증해야 합니다.
