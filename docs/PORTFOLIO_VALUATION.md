# 포트폴리오 평가 계약

`portfolio-analyze`는 저장된 현재 포지션 스냅샷과 Yahoo 가격을 결합해
평가금액, 미실현손익과 집중도를 계산합니다. 자동 주문이나 매수·매도 지시는
생성하지 않습니다.

## 실행

```powershell
go run ./cmd/forgetmenot portfolio-analyze -output text
go run ./cmd/forgetmenot portfolio-analyze -ticker AAPL -output json
```

기본 집중도 임계값은 검토 2,500bp(25%), 고집중 4,000bp(40%)입니다.

```powershell
go run ./cmd/forgetmenot portfolio-analyze -watch-bps 2000 -high-bps 3500
```

임계값은 위험 검토 우선순위를 정하기 위한 설정이며 수익 가능성이나 매매 방향을
뜻하지 않습니다.

## 계산

금액과 수량은 소수점 8자리 고정소수점으로 계산합니다.

- 평가금액 = 현재수량 x 최근가격
- 총 노출액 = 평가금액의 절댓값
- 원가 = 현재수량 x 평균취득단가
- 미실현손익 = 평가금액 - 원가
- 집중도 = 종목 총 노출액 / 같은 통화의 전체 총 노출액

집중도 분모에 순평가금액이 아니라 총 노출액을 사용합니다. 롱 포지션과 숏 포지션이
서로 상계되어 실제 노출 위험이 작아 보이는 것을 막기 위해서입니다.

## 통화 정책

KRW, USD처럼 통화가 다른 금액은 환율 없이 합산하지 않습니다. 결과의
`cross_currency_aggregation`은 `not_performed`이며 통화별 합계만 제공합니다.
환율 공급자, 기준시각과 환산 정책이 추가되기 전에는 전체 원화 평가액 같은 값을
만들지 않습니다.

## 부분 데이터

- 현재 포지션 행이 없으면 보유수량 0으로 간주하지 않습니다.
- 수량이 0이면 가격을 요청하지 않고 0원 포지션으로 평가합니다.
- 평균취득단가가 0이면 평가금액은 계산하지만 원가와 미실현손익은 계산하지 않습니다.
- 가격이 없거나 포지션 통화와 가격 통화가 다르면 해당 종목을 평가하지 않습니다.
- 가격 출처의 provider, URL 또는 수집시각이 없으면 부분 데이터로 표시합니다.
- 한 종목의 가격 수집 실패는 다른 종목의 평가를 중단시키지 않습니다.

각 문제는 종목별 `issues`에 기록되고 전체 상태는 `partial`로 표시됩니다.
