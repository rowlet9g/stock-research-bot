# 가격 지표 계약

Yahoo Finance의 6개월 일봉에서 아래 지표를 Go 코드로 계산합니다. 공급자 원본
응답에 없는 값을 AI가 계산하거나 추정하지 않습니다.

## 버전

현재 계산 버전은 `yahoo-price-metrics/v1`, 가격 신호 규칙 버전은
`price-signals/v2`입니다.

## 계산식

| 지표 | 계산 |
| --- | --- |
| 1일 수익률 | `(최근 종가 / 직전 종가 - 1) x 100` |
| 20일 수익률 | `(최근 종가 / 20거래일 전 종가 - 1) x 100` |
| 60일 수익률 | `(최근 종가 / 60거래일 전 종가 - 1) x 100` |
| 20일 연율화 변동성 | 최근 20개 일간 로그수익률의 표본 표준편차 x `sqrt(252)` x 100 |
| 60일 연율화 변동성 | 최근 60개 일간 로그수익률의 표본 표준편차 x `sqrt(252)` x 100 |
| 6개월 최대 낙폭 | `min(종가 / 당시까지의 최고 종가 - 1) x 100` |
| 거래량 배수 | 최근 거래량 / 직전 20거래일 평균 거래량 |

20·60일 수익률과 변동성은 각각 21개, 61개 유효 종가가 있어야 계산합니다.
거래량 배수는 최근 거래일 이전의 연속된 20개 거래량이 모두 있어야 계산합니다.
누락된 값은 0으로 대체하지 않습니다.

## 기본 위험 임계값

| 규칙 | 기본값 |
| --- | ---: |
| 1일 절대 변동률 | 5% 이상 |
| 20일 하락 수익률 | -15% 이하 |
| 20일 연율화 변동성 | 40% 이상 |
| 6개월 최대 낙폭 | -20% 이하 |
| 거래량 배수 | 2배 이상 |

이 값은 매매 기준이 아니라 추가 확인이 필요한 관측 신호입니다. 각 신호는 규칙 ID,
실측값, 비교 방식, 임계값과 계산식을 함께 반환합니다.

## 데이터 품질

0 이하, `NaN`, 무한대 종가는 유효 가격으로 사용하지 않고 부분 데이터 경고를
남깁니다. 가격이 부족하면 해당 지표를 생략하며 정상값처럼 0을 반환하지 않습니다.
