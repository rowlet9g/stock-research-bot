# 포트폴리오 행동 중심 검토 요청

현재 입력만으로 실행 가능한 위험관리 판단을 우선 제시해 줘. 자료 부족을 반복해서
설명하거나 보유 비중을 그대로 다시 나열하지 말고, 각 수치가 어떤 조치로 이어지는지
분명하게 써 줘.

## 판단 원칙

- 기업가치 판단 자료가 없더라도 가격 결과와 집중도에 근거한 기본 조치는 제시한다.
- `high` 종목은 추가 매수를 우선 보류하고, 제공된 40% 기준 재배분액을 1차
  위험관리안으로 검토한다.
- `watch` 종목은 추가 매수보다 현재 비중 유지 또는 점진적 축소를 우선 비교한다.
- 투자 가설이 없으면 결론 전체를 유보하지 말고 `가설 확인 전 기본 조치`를 제시한다.
- 평균단가 대비 손익과 이동평균을 이용해 가격 타이밍 결과가 유리했는지 불리했는지
  직접 평가하되, 이를 기업가치 판단과 구분한다.
- 수량이 0인 종목은 본문에서 언급하지 않는다.
- 신규 후보 자료가 없으면 종목명을 만들지 말고, 당장 보완해야 할 노출 특성만 한
  문단으로 정리한다.

## 원하는 답변

1. 핵심 결론: 지금 유지할 것, 추가 매수를 멈출 것, 비중을 먼저 줄여 검토할 것을
   5문장 이내로 제시한다.
2. 즉시 행동안: KRW와 USD별로 40% 기준의 구체적인 재배분 참고액과 단계적 실행
   순서를 제시한다. 25% 기준은 장기 분산안으로만 구분한다.
3. 활성 종목 판단: 종목마다 한 줄로 `가격 타이밍 평가 / 기본 조치 / 판단을
   바꿀 조건`을 제시한다.
4. 추가 매수와 신규 편입: 지금 추가 가능한지, 보류해야 하는지와 그 이유를
   간결하게 제시한다.
5. 다음 확인사항: 결론을 실제로 바꿀 수 있는 자료만 중요도 순으로 최대 5개 적는다.

별도의 데이터 범위, 강점, 가격 출처, 시나리오 설명, 일반적인 투자 원칙 절은 만들지
마. 데이터 한계는 해당 권고 바로 뒤에 한 문장으로만 붙여 줘.

Markdown 제목, 굵게 표시, 표, 코드 표시를 사용하지 말고 일반 텍스트로 작성해 줘.
전체 분량은 2,500~4,000자 정도로 제한하고, 직접적이되 자동 주문이나 무조건적인
매수·매도 명령으로 표현하지 마.
사람이 읽는 금액은 KRW는 정수, USD는 소수점 둘째 자리까지만 반올림해 표시해 줘.
