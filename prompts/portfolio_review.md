# 포트폴리오 종합 검토 요청

제공된 포트폴리오 평가, 시장 지표, 투자 가설, 리밸런싱 참고액과 시나리오만 근거로 현재 포트폴리오를 검토해 줘.
단순히 보유 비중을 나열하지 말고, 아래 질문에 답할 수 있는 근거와 아직 답할 수 없는 이유를 분리해 줘.

## 1. 핵심 진단

- KRW와 USD를 각각 분석하고, 통화별 손익·집중도·추세·변동성·낙폭에서 가장 중요한 사실을 우선순위대로 정리해 줘.
- 현재 포트폴리오의 강점, 취약점, 한 종목이나 한 요인에 대한 의존도를 설명해 줘.
- 데이터가 오래됐거나 빠져 있으면 분석 결론보다 먼저 밝혀 줘.

## 2. 매수가격 검토

- 각 보유 종목의 평균단가 대비 수익률, 최근 가격 추세, 이동평균선, 변동성, 최대낙폭과 거래량을 함께 검토해 줘.
- 현재 손익만으로 매수가가 좋았거나 나빴다고 단정하지 말고, 그렇게 판단하려면 필요한 밸류에이션·실적·산업 데이터가 무엇인지 밝혀 줘.
- 물타기나 손절을 전제로 하지 말고, 매수 당시 가설을 현재 데이터로 검증할 수 있는지 평가해 줘.

## 3. 보유 전략 검토

- 수량이 0이 아닌 각 종목을 `유지 검토`, `주의 관찰`, `비중 재검토` 중 하나로 분류해 줘.
- 분류마다 사실, 가능한 해석, 반론, 투자 가설의 무효화 조건, 다음 확인 지표를 제시해 줘.
- 투자 가설이 등록되지 않은 종목은 판단을 만들어내지 말고 필요한 질문을 먼저 제시해 줘.

## 4. 리밸런싱 선택지

- 제공된 같은 통화 내 리밸런싱 참고액만 사용해 `현 상태 유지`, `점진적 조정`, `즉시 재검토 필요` 시나리오를 비교해 줘.
- 각 시나리오의 목적, 기대 효과, 단점과 실행하지 않을 반론을 설명해 줘.
- 세금, 수수료, 환율과 유동성 효과가 계산되지 않았다면 숫자에 포함된 것처럼 표현하지 마.

## 5. 추가 매수 검토

- 기존 보유 종목의 추가 매수와 신규 종목 탐색을 분리해 줘.
- 기존 종목은 가설이 유효하고 집중 위험이 악화되지 않는지 먼저 검토해 줘.
- 신규 후보 데이터가 제공되지 않았다면 구체적인 종목명을 추천하지 말고, 현재 포트폴리오의 빈 노출 영역과 후보가 갖춰야 할 특성·검증 자료를 제시해 줘.

## 6. 시나리오와 실행 전 확인

- 하락·중립·상승 시나리오는 예측이 아닌 기계적 민감도로 설명해 줘.
- 마지막에는 결론을 바꿀 수 있는 누락 데이터와 다음 조사 순서를 중요도 순으로 정리해 줘.
- 자동 주문이나 확정적 매수·매도 지시 대신 `현재 근거로 가능한 판단`, `판단 보류`, `추가 확인 필요`를 명확히 구분해 줘.

## 답변 구성

1. 세 문장 이내의 핵심 요약
2. 통화별 포트폴리오 상태
3. 활성 보유 종목별 검토 표
4. 리밸런싱 시나리오 비교
5. 추가 매수 검토 기준
6. 누락 데이터와 우선 확인 목록

각 절에서 `사실`, `해석`, `반론`, `확인 질문`을 구분하고, 가능한 경우 가격의 provider, source URL, observed_at과 fetched_at을 근거 옆에 표시해 줘.
